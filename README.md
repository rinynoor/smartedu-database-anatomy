Inside SmartEdu — Interactive Database Anatomy

See what happens inside a database when SQL runs.

An interactive learning tool for university students studying relational databases and SQL through a fictional academic system called SmartEdu.

Try the app

▶ Open the interactive SmartEdu app

Open the link in a browser. No installation or account is required.

What you can explore

Inspect six related tables: STUDENT, LECTURER, COURSE, SEMESTER, CLASS, and ENROLLMENT.

Follow primary keys, foreign keys, columns, and sample rows.

See step-by-step demonstrations of SELECT, INSERT, UPDATE, DELETE, and a four-table JOIN.

Experiment with constraints, complete SQL challenges, and track learning progress.

Important note

The SQL console is an Oracle SQL Simulation running in the browser. It supports an educational subset of SQL and does not connect to Oracle AI Database 26ai. The example data and learning progress are stored in the visitor's browser and can be reset from the app.

Run locally

Download index.html from this repository and open it in a browser.
